# Technology Learning Guide

A lightweight learning guide created for Computer Engineering students preparing to work on a university software project.

The goal of the project was to provide a structured and accessible learning path for the main technologies used by the team, combining curated documentation, educational resources, short explanations and knowledge checks.

## Live Demo

https://guia-tecnologica.vercel.app/

## Topics Covered

- TypeScript
- React
- Next.js
- PostgreSQL & PostGIS
- Drizzle ORM
- Better Auth
- Leaflet & React-Leaflet
- Docker & Docker Compose

## Purpose

The guide was designed to help team members quickly build a common technical foundation before making architecture and development decisions.

Rather than replacing official documentation, it provides a curated learning order, highlights the most relevant concepts for the project, and links to external resources for deeper study.

## Implementation

This is a simple static single-page website built with HTML, CSS and JavaScript and deployed on Vercel.
