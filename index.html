type SelectedPoint = {

function PointSelector({
  value,
  onChange,

Validaciones server-side

Puertos, redes y persistencia

Un contenedor tiene su propio namespace de red y un filesystem descartable. La comunicación y los datos persistentes deben declararse.

Networking

  • localhost dentro del contenedor significa ese contenedor.
  • Compose ofrece DNS por nombre de servicio.
  • ports publica hacia el host.
  • expose o el puerto interno no publican por sí solos.

Storage

  • Writable layer: temporal.
  • Bind mount: ruta concreta del host.
  • Named volume: datos administrados por Docker.
  • Object storage: persistencia externa desacoplada.
